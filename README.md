# 噢麦嘎｜2026 劳饭年度报告

> **参赛项目**：[麦当劳程序员创意开发大赛](https://github.com/M-China/mcd-developer-innovation-challenge)  
> **定位**：读取用户的麦当劳订单（通过麦当劳 MCP `order-list`），从时间、渠道、单品、金额四个维度统计出「麦门人格」，生成一张能直接发朋友圈的 3:4 竖版年度海报。

**核心差异**：不是又一个"凑券省钱"工具——这是一面**数据驱动的麦门镜子**。  
你可能以为自己只是偶尔点个外卖，数据会告诉你：你是深夜续命的黑马、工作日打卡的班马，还是甜品治愈派。

---

## 快速开始

### 1. 本地运行（需要你的真实订单）

```bash
# 1. 设置 Token（从麦当劳开发者平台获取）
export MCD_MCP_TOKEN="your_token_here"

# 2. 启动本地桥接（提供页面 + MCP 调用）
python mcp_bridge.py

# 3. 浏览器打开 http://127.0.0.1:8765/，点击「读取我的订单」
```

桥接服务会调用麦当劳 MCP 的 `order-list` 和 `now-time-info`，只保留下单时间、渠道、金额、商品名，**不含订单号、门店、地址、手机号**。脱敏后的数据传给前端，全部统计在浏览器本地完成，不上传任何服务器。

### 2. 演示模式（无需 Token）

直接打开 `index.html`（file:// 或静态托管），页面会自动加载八种人格的演示数据。点击右下角的人格缩略图可以切换，海报会标注「演示样本 · 非真实订单」。

## 工作原理

| 步骤 | 说明 | 技术栈 |
|------|------|--------|
| **1. 读订单** | `mcp_bridge.py` 用你的 Token 调用麦当劳 MCP `order-list` | Python 3.8+，零依赖 MCP 客户端（`mcd_client.py`） |
| **2. 脱敏** | 只保留 `{createTime, orderType, realTotalAmount, items[]}`，丢弃个人信息 | 服务端白名单字段 |
| **3. 算人格** | 浏览器统计 20+ 项指标：工作日占比、深夜单数、甜品频率、复购率、尝鲜种类、高光大单… | `app.js`（纯数据层，可在 Node 里跑单元测试） |
| **4. 出海报** | 用 Canvas 把真实数字画到 Seedream 生成的人格海报底部的三张卡片上 | `poster.js` + `index.html` |

## 八型人格

每种人格按订单行为独立打分（0–100），得分最高者胜出：

| 人格 | 类型 | 判定规则 | 海报文案 |
|------|------|---------|---------|
| **班马** | 麦门打卡型 | 工作日下单占比高 | 一个人，活成了一个班。白天上班，晚上上麦。 |
| **深夜黑马** | 续命型 | 22:00—05:00 订单多 | 别人收工，你开始给自己加餐。夜色越深，麦门信号越强。 |
| **甜品治愈派** | 情绪补给型 | 甜品出现频率高 | 心情可以打折，甜筒不能缺席。甜不是答案，但很有效。 |
| **卡急马** | 下班冲刺型 | 工作日 17:30—19:00 集中下单 | 下班铃一响，我踏马就来了。把晚餐安排得比人生更快。 |
| **麦门痴心人** | 经典守护型 | 同一单品反复复购 | 不是不尝新，是这口旧爱值得反复。每次都点它，是一种坚定。 |
| **麦门探险家** | 尝鲜型 | 尝过的单品种类多 | 菜单不是菜单，是未探索地图。你负责探索。 |
| **麦乐送常驻民** | 到家型 | 外送订单占比高 | 人可以不出门，快乐准时到家。你的麦门地址，熟得像老朋友。 |
| **麦门显眼包** | 高光型 | 有明显高于日常的高光大单 | 这顿必须认真吃，仪式感不能输。不是爱晒，是数据确实很有戏。 |

## 技术亮点

1. **零依赖 MCP 客户端**  
   `mcd_client.py` 只用标准库实现了 Streamable HTTP（JSON + SSE），支持 401/429 重试、fixtures 回放（便于演示与测试）。

2. **确定性演示数据**  
   `app.js` 里的 `buildDemoOrders()` 用 Mulberry32 伪随机生成器，同一人格每次生成的订单完全一致，方便复现与自动化测试。

3. **纯前端统计 + Canvas 合成**  
   订单数据到海报的全流程在浏览器本地完成，不依赖后端图像处理。`poster.js` 用 Canvas 把真实数字精准覆盖到预设卡片位置，输出即分享。

4. **安全第一**  
   - 桥接服务的 CORS 只允许本机来源（`127.0.0.1`/`localhost`），拒绝跨域请求
   - 返回字段白名单：只传 `{createTime, orderType, realTotalAmount, items[]}`，不含订单号、门店、地址、手机号
   - Token 只留在你本机的环境变量里，页面里看不到
