# 噢麦嘎｜2026 劳饭年度报告

一个基于麦当劳 MCP 订单数据的个人年度报告原型：读取订单时间、渠道、金额和商品偏好，生成八种“麦门人格”，并展示对应的年度海报。

## 当前可用能力

- 八种人格海报点击切换；
- 3:4 完整海报预览；
- 脱敏订单 JSON 导入；
- 订单统计：订单数、工作日占比、深夜订单、外送占比、高频单品、最高单笔；
- MCP 本地安全桥接入口；
- 无真实订单时明确回退到演示数据。

## 运行预览

直接打开 `gallery-preview-standalone.html` 查看八张海报画廊。

打开 `report.html` 查看数据分析页面。

## 接入 MCP

1. 在终端设置环境变量 `MCD_MCP_TOKEN`。
2. 启动 `mcp_bridge.py`。
3. 打开 `report.html`，点击“从本地 MCP 桥接读取订单”。

Token 只在本地桥接服务中使用，不写入前端文件、不提交仓库。

## 重要说明

本项目当前是可运行原型。若 MCP 返回空订单，页面会使用演示数据并明确标注；不把演示数字伪装成真实用户年度数据。
